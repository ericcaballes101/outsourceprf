Payment Request Form (PRF) Generator

Upload the SOA, the charging-code file and the PRF template. The PRF lines (account codes, T0–T9, purpose) are built for you and downloaded as an Excel file. Everything runs in your browser. No file is uploaded anywhere.

1 Upload the three files

Click a box or drag files onto it. You can also drop all three files on any box at once and they will be sorted automatically.

2 Check the header details

These were read from the files. Change anything that needs it and the PRF below updates.

Expense coding rules (from the template's INVOICE sheet)

Cost centres (numeric account code) use the account code shown and T2 = #. Projects (code starting with a letter) keep their project code and use the T2 shown. For Basic Charge and Overtime the project T2 from the charging file is used when it is a valid 8xxxx code.

3 PRF output

    Add SOAs to the report

    Drop one or more SOA PDFs (either layout). A PRF you download in the generator is added to the report automatically, so its SOA shows as "PRF created".
